# Temas Ghost

Dois temas prontos, ambos validados com o GScan (0 erros):

## comenta/
Tema de blog limpo, gradiente roxo/magenta, responsivo. Para o dominio Comenta.

## hojemt/  (v1.5.0)
Portal de noticias "Hoje MT" no estilo jornal — verde esmeralda, slider de capa,
editorias, videos, banners publicitarios, chat flutuante, popup de newsletter (1x por
sessao) e botao Picture-in-Picture nativo para os videos.

## Instalar um tema
No Ghost Admin: **Settings → Design → Change theme → Upload theme**, envie o `.zip` da
pasta do tema e clique **Activate**. Para gerar o zip:

```bash
cd theme && zip -rX ../hojemt.zip hojemt
```
